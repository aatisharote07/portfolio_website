## Project Overview

An end-to-end ETL pipeline that extracts real-time weather data from the OpenWeatherMap API, transforms it using Apache Spark, and loads it into PostgreSQL. The workflow is orchestrated with Apache Airflow and includes logging, error handling, and a Flask-based visualization layer.
